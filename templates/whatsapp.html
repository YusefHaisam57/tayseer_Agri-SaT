⚙️ دليل الإعداد للمطورين (Ngrok + Twilio)

1. شغّل ngrok للحصول على رابط عام:

ngrok http 5000

2. في Twilio Console → Messaging → WhatsApp Sandbox:

When a message comes in → https://xxxx.ngrok.io/api/webhook/whatsapp

3. أضف متغيرات البيئة في ملف .env:

TWILIO_ACCOUNT_SID=ACxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxx
TWILIO_WHATSAPP_NUMBER=whatsapp:+14155238886

4. تثبيت Twilio:

uv add twilio python-dotenv
